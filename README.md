# Student Management System
A simple web-based Student Management System built with Node.js, Express, EJS, and MySQL.

## Features
- View students
- Add students
- Edit students
- Delete students (with confirmation)
- Search by Student ID, name, or course
- Form validation

## Technologies Used
Node.js, Express.js, EJS, MySQL, Git, GitHub

Installation
1. Clone the repository: git clone https://github.com/sajjmin/student-management.git
2. Go into the folder: cd student-management
3. Install dependencies: npm install
4. Start MySQL in XAMPP and create the student_management database using phpMyAdmin.
5. Create a .env file in the project folder:
   DB_HOST=localhost
   DB_USER=root
   DB_PASSWORD=
   DB_NAME=student_management
6. Run the app: node app.js
7. Open http://localhost:3000
